# Books Web Scraper

A web scraping project using Python, Requests, BeautifulSoup, and Pandas.

## Features

- Scrapes 1000 books
- Extracts book titles
- Extracts prices
- Extracts ratings
- Extracts availability
- Extracts image URLs
- Extracts product URLs
- Handles pagination
- Saves the scraped data as a CSV file

## Technologies

- Python
- Requests
- BeautifulSoup
- Pandas

## Dataset

The scraper collects data from Books to Scrape.

## Output

The scraper generates a CSV file containing 1000 books and 6 features.
